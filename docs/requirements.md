# 요구사항 명세 — ground-station-rx (위성 지상국 수신 처리)

> 원시 IQ 녹음에서 위성 프레임까지 — 궤도로 도플러를 예측해 보정하고, 복조·비터비·CCSDS 채널 복호를 거쳐 텔레메트리를 꺼낸다.
> 채널 복호 뒷단(ASM · PN · RS · TM 프레임 · 패킷)은 [SpaceLink](https://github.com/Haejyn/ccsds-downlink-reliability) v1.1 을 서브모듈로 재사용한다.
> 시험 코드는 `[Trait("Requirement", "REQ-…")]` 로 요구사항을 가리킨다.

## 핵심 계약

> **정답은 구현 밖에서 가져온다.** 궤도는 Vallado 의 SGP4 공식 검증 출력과 독립 구현(Skyfield), 신호는 실제 위성 녹음과
> 다른 지상국의 복호 결과로 판정한다. 이 저장소가 스스로 만든 값으로 자기 자신을 시험하지 않는다.

## 기능 요구사항

| ID | 요구사항 | 판정 기준 |
|---|---|---|
| REQ-ORB-01 | SGP4 근지구 전파가 Vallado 기준 구현과 같은 궤도를 낸다. 심우주 궤도(주기 225 분 이상)는 조용히 틀리지 않고 거부한다 | Vallado `SGP4-VER.TLE` 의 근지구 9 개 전부 · `tcppver.out` 158 시점 — 위치 1 μm·속도 0.01 mm/s 미만 차이. 심우주 사례 전부 거부. 대기권 진입은 오류 6(Decayed) |
| REQ-ORB-02 | TLE 를 고정 열 위치대로 읽고, 형식 오류·체크섬 오류·행 번호 불일치는 거부한다 | 필드 값 전부 일치. **한 자리 숫자 오류 전수**(두 행의 모든 숫자 × 다른 숫자 9 개) 거부. Vallado 가 일부러 망가뜨린 사례 3 개 거부 |
| REQ-ORB-03 | 위성–지상국 거리·거리 변화율·고도각을 계산한다 | JD(J2000) · GMST(Vallado 예제 3-5) 일치. ASRTU-1 실제 패스 12 분(73 점)에서 Skyfield 대비 거리 0.5 km · 거리 변화율 0.1 m/s · 고도각 0.02° 이내. 접근 중 도플러 +, 최근접에서 부호 반전 |
| REQ-ORB-04 | 궤도로 예측한 도플러가 실제 녹음의 반송파 변화를 설명한다 | ASRTU-1 녹음(2024-12-09, 드빙겔로) 두 버스트의 반송파를 0.2 초마다 재어 예측 도플러를 뺀 잔차 — 버스트별 중앙값 차이 2 Hz 미만(그 사이 예측 도플러 변화는 약 120 Hz) |
| REQ-DOP-01 | BPSK 반송파 주파수를 변조와 무관하게 재고, 기대 주파수 창 밖의 신호는 무시한다 | FFT 가 직접 DFT 와 일치. 합성 BPSK(SNR 5~20 dB, ±240 kHz) 에서 0.5 Hz 이내. 창 밖의 16 배 센 신호가 있어도 창 안 목표를 0.5 Hz 이내로 재고, 창이 없으면 방해 신호를 고른다 |
| REQ-REC-01 | SigMF 녹음(ci16_le · cf32_le · cu8)의 메타데이터와 표본을 읽는다 | 형식별 표본 값 · 시각(100 ns) · 끝 넘김 처리 일치. 지원 않는 형식 · capture 여러 개 · 데이터 파일 없음은 거부. 실제 ASRTU-1 녹음 67,720,000 표본 |
| REQ-DEM-01 | BPSK 버스트를 연판정 심볼로 복조한다 — 심볼율 오차·소수 타이밍·잔여 반송파를 버스트 안에서 스스로 추정한다 | 합성 신호(9600.7 baud, 타이밍 0.37 심볼, 반송파 ±10 Hz) 잡음 없이 20,000 심볼 오류 0 · 심볼율 0.05 Hz 이내. Eb/N0 2·4·6 dB 에서 BER 이 이론 ½·erfc(√(Eb/N0)) 대비 **±0.5 dB 안**(더 나빠도, 더 좋아도 실패) |
| REQ-FEC-01 | CCSDS 길쌈 부호(K=7, r=1/2, G2 반전)를 연판정 비터비로 복호한다 | 잡음 없이 왕복 일치. 채널 심볼 전부 반전 → 복호 비트 전부 반전(→ NRZ-M 이 흡수). Eb/N0 3 dB 에서 BER ≤ 1.5e-3, 4.5 dB 에서 ≤ 3e-5, 부호 없는 BPSK 보다 10 배 이상 좋음 |
| REQ-FEC-02 | 관례 기저 RS(255,223) 를 복호한다(SpaceLink 이중 기저 복호기 + 기저 변환) | 독립 구현(reedsolo)이 만든 부호어 680 개(오류 0~16 개 × 40) 전부 원래 데이터·정정 수 일치. 기저 변환 256 값 왕복. 오류 17 개 200 회 — 원래 데이터라고 말한 적 0, 실패 선언 190 회 이상 |
| REQ-RX-01 | 원시 IQ 녹음에서 전송 프레임을 복원한다 | ASRTU-1 녹음(68 초, 버스트 2 개)에서 RS 실패 0. TM 프레임 12 장 전부 SCID 50 · 가상 채널 0/2, **마스터 채널 카운트가 두 버스트에 걸쳐 빈틈없이 연속**(놓친 프레임 0). 위성의 비표준 데이터 필드 상태(세그먼트 길이 ID 00)를 SpaceLink 가 가려낸다 |
